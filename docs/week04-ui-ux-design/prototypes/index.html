WEEK 04 UI/UX DESIGN EXPLORATION

Telecom Router Topology Visualizations

To address the visual clutter of 554 telecom devices (Peering, National Border, Core, Edge Aggregation, Metro Exchange, and 480 Access Switches) without losing hierarchical context, we engineered and evaluated three interactive NOC visualization paradigms. After the UX trade-off review, Approach 01 — Stratified Tiered Canvas was selected as the primary architecture (Approaches 02 & 03 were evaluated and removed). It implements k-hop ego-network focus, expandable access leaf badges, and dynamic sub-graph pruning on strict fixed tier bands.

APPROACH 01 · SELECTED Layered Bands

Stratified Tiered Canvas

Strict top-to-bottom tier bands (Peering → Border → Core → Aggregation → Exchange → Access). When focusing on a router, visible nodes maintain horizontal tier rows while distant nodes smoothly dim or prune. Access nodes are summarized as leaf badges (+14 ACC) with 1-click blooming.

✓ 100% hierarchy preservation (REQ-01 / REQ-06)
✓ Fast search & breadcrumbs
✓ Expandable access leaves

Dataset Ingestion & Graph Topology

Derived directly from Viettel's devices.csv (558 records) and links.csv (632 records). The 78 core/aggregation/exchange routers are modeled as primary nodes, while 480 access switches are clustered under their respective 36 Exchange hubs as interactive expandable leaves.

Zero-Server Standalone Architecture

All prototype files are completely standalone and runnable via file:// protocol or any static web server without CORS errors or build steps. Built with Tailwind CSS CDN and D3.js v7 with responsive vector SVG navigation.
