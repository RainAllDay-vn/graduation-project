TƯƠNG TÁC

Bấm một cảnh báo / mã lỗi

Bấm cảnh báo → canvas pan + focus thiết bị (3.5). Bấm mã lỗi → panel tài liệu trượt sát mép trái canvas, đè một phần topology; × hoặc Esc đóng, canvas về đúng trạng thái trước đó; wiki mở tab mới (4.2).

Bấm một dòng danh sách thiết bị

Chọn thiết bị → Inspector chuyển sang dải định danh + ba tab, canvas pan đưa node về giữa — như tìm kiếm (5.0, 4.1). Nút ← bỏ chọn, trở về danh sách.

Bấm đúp node → beacon

Vòng beacon trắng bao node (layer riêng); node trong bán kính K = 2 giữ nguyên, ngoài vùng mờ đi kèm edge — chế độ Mờ/Ẩn và K chỉnh ở tab Cài đặt (4.4). Được phép nhiều beacon cùng lúc (3.5).

Giả thuyết AI & chọn edge

Bấm card giả thuyết → khoanh vùng nghi vấn + beacon thiết bị liên quan, chi tiết mở accordion tại chỗ; Xác nhận/Bác bỏ ở cuối chi tiết (4.3). Bấm edge trên canvas → Inspector hiện hàng hai đầu kèm cổng thay thanh tab (5.4).

Pan · zoom · kéo node · tooltip

Kéo nền để pan, kéo node để chỉnh bố cục, lăn chuột zoom quanh con trỏ; zoom-out quá ngưỡng → LOD mức xa (3.1–3.3). Hover node/edge có tooltip đầy đủ đi theo con trỏ, không làm canvas thay đổi (3.4).
