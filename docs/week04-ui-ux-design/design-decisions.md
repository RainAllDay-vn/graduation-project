## 3. Chương 2 — Edges (chốt)

- **Nhãn edge không bao giờ hiện** ở mọi mức zoom — chi tiết thuộc tooltip/inspector (mục 2.5 đã xóa).
- Màu edge = trạng thái sức khỏe, **2 mức**: healthy `#10b981` · critical **đỏ sáng `#ef4444`** (khác nền đỏ đậm node vì nét mảnh cần nổi; trùng màu link critical cũ của prototype). Độc lập với trạng thái 2 đầu node.
- Độ dày = băng thông lắp đặt, **3 bậc**: mảnh (<10G) / trung (10G–<100G) / dày (≥100G).
- Nét = utilization liên tục: không dùng → đứt → càng dùng càng liền → liền trọn ở 100%.
- Data hiện tại: 1295 healthy / **89 warning** / 36 critical — **89 warning chưa có quy tắc map khi sync** (pending). Capacity chỉ có 10G (496 link) + 100G (288); utilization 0–100 liên tục.
